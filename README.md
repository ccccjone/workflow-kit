# workflow-kit

给 AI 编程助手用的项目初始化模板集合。每个子目录对应一种工具，新建项目时用对应目录里的安装脚本（或手动拷贝）装进你的 repo。

| 目录 | 适用工具 | 说明 |
|---|---|---|
| [claude-workflow-kit/](./claude-workflow-kit/) | Claude Code | spec 分级 / plan-first / TDD / 混合执行 / hooks 强制验收，`install.sh` 安装，详见 [README.md](./claude-workflow-kit/README.md) |

> 后续计划补充：`codex-workflow-kit/`、`kiro-workflow-kit/` 等。
